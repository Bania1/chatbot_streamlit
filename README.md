☝️ Chatbot Básico con Langchain + Streamlit
¡Bienvenido/a a tu primer Chatbot hecho con Langchain y Streamlit!
Interactúa con un asistente amigable y personaliza la experiencia con modelos LLM de OpenAI.
Esta app es perfecta para aprender, experimentar y explorar el poder del lenguaje natural en Python.

🚀 Demo interactiva
Simplemente clona el repositorio, instala los requisitos y ejecuta la app localmente.
¡Comienza a conversar en cuestión de segundos!

✨ Características principales
Configuración en tiempo real: Ajusta la temperatura y elige el modelo OpenAI preferido desde el sidebar.

Historial de conversación: Cada sesión mantiene el contexto para respuestas más naturales.

Interfaz amigable: UI moderna y simple creada con Streamlit para una experiencia de usuario agradable.

Fácil personalización: Plantilla de prompts flexible y código comentado para adaptar a tus necesidades.

🏗️ ¿Cómo funciona?
Selecciona el modelo y la temperatura desde la barra lateral.

Escribe tu mensaje y recibe respuestas generadas automáticamente.

Reinicia cuando quieras con el botón "Nueva conversación".

Visualiza todo el historial de intercambio cómodamente.

Tecnologías empleadas:

Langchain: Cadena para el manejo avanzado de prompts y modelos de lenguaje.

Streamlit: Framework rápido para construir apps web interactivas en Python.

OpenAI API: Modelos LLM como GPT-3.5 y GPT-4.

✍️ Instalación rápida
bash

# Clona este repositorio

git clone https://github.com/Bania1/chatbot_streamlit.git
cd chatbot_streamlit

# Instala dependencias

pip install -r requirements.txt

# Ejecuta la app

streamlit run app.py
Asegúrate de tener tu API Key de OpenAI correctamente configurada.
