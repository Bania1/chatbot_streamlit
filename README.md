# 🤖 Chatbot Básico con LangChain + Streamlit

¡Bienvenido/a a tu primer chatbot hecho con **LangChain** y **Streamlit**!  
Interactúa con un asistente amigable y personaliza la experiencia usando modelos LLM de **OpenAI**.  
Esta app es perfecta para **aprender**, **experimentar** y **explorar** el poder del lenguaje natural en Python.

---

## 🚀 Demo interactiva

Clona el repositorio, instala los requisitos y ejecuta la app localmente.  
¡Comienza a conversar en cuestión de segundos!

---

## ✨ Características principales

✅ **Configuración en tiempo real**  
Ajusta la temperatura y elige el modelo de OpenAI desde la barra lateral.

💬 **Historial de conversación**  
Cada sesión mantiene el contexto para respuestas más naturales.

🎨 **Interfaz amigable**  
Diseño moderno y limpio con Streamlit, para una experiencia agradable.

🧩 **Fácil personalización**  
Código comentado y plantilla de prompts flexible para adaptar a tus necesidades.

---

## 🏗️ Cómo funciona

1. Selecciona el **modelo** y la **temperatura** desde la barra lateral.
2. Escribe tu mensaje y recibe una respuesta generada automáticamente.
3. Reinicia cuando quieras con el botón **"Nueva conversación"**.
4. Visualiza el historial completo de la charla.

---

## ⚙️ Tecnologías empleadas

| Tecnología        | Descripción                                                   |
| ----------------- | ------------------------------------------------------------- |
| 🧠 **LangChain**  | Cadena para manejo avanzado de prompts y modelos de lenguaje. |
| 🌐 **Streamlit**  | Framework rápido para crear apps web interactivas en Python.  |
| 🔑 **OpenAI API** | Modelos LLM como GPT-3.5 y GPT-4.                             |

## 🧰 Instalación rápida

Asegúrate de tener Python instalado (versión 3.10 o superior). Luego:

```bash
# 1️⃣ Clona este repositorio
git clone https://github.com/Bania1/chatbot_streamlit.git
cd chatbot_streamlit

# 2️⃣ Instala las dependencias necesarias
pip install -r requirements.txt

# 3️⃣ Ejecuta la aplicación
streamlit run app.py
⚠️ Importante: Antes de ejecutar, configura tu API Key de OpenAI como variable de entorno:

bash
Copiar código
export OPENAI_API_KEY="tu_api_key_aquí"
En Windows (PowerShell):

bash
Copiar código
setx OPENAI_API_KEY "tu_api_key_aquí"
```
